默认全量测试不会触达真实服务；只有显式设置 `QWSAAS_REAL_TESTS=1` 才会跑真实接口，只有再设置 `QWSAAS_REAL_SEND_TESTS=1` 才会发送消息。

Hermes 本机 `.env` 可直接作为凭据来源，复跑命令如下：

```bash
set -a
source /Users/chou/.hermes/.env
set +a

export QWSAAS_REAL_TESTS=1
export QWSAAS_REAL_SEND_TESTS=1
export QWSAAS_STORAGE_ENDPOINT_URL="${JUHE_S3_ENDPOINT_URL:-}"
export QWSAAS_STORAGE_BUCKET="${JUHE_S3_BUCKET:-}"
export QWSAAS_STORAGE_ACCESS_KEY="${JUHE_S3_ACCESS_KEY:-}"
export QWSAAS_STORAGE_SECRET_KEY="${JUHE_S3_SECRET_KEY:-}"
export QWSAAS_STORAGE_REGION="${JUHE_S3_REGION:-us-east-1}"
export QWSAAS_STORAGE_PREFIX="${JUHE_S3_PREFIX:-qwsaas-real-test}"
export QWSAAS_STORAGE_ADDRESSING_STYLE="${JUHE_INBOUND_S3_ADDRESSING_STYLE:-path}"
export QWSAAS_STORAGE_URL_EXPIRES_SECONDS="${JUHE_S3_URL_EXPIRES_SECONDS:-900}"

uv run --extra dev pytest tests/real -q
```

# qwsaas v0.3.0 真实测试需求文档

日期：2026-05-21

适用范围：`qwsaas v0.3.0`

关联文档：

- 设计文档：`docs/superpowers/specs/2026-05-21-qwsaas-v0.3.0-design.md`
- 实施计划：`docs/superpowers/plans/2026-05-21-qwsaas-v0.3.0-implementation.md`

## 目标

这份文档回答三个问题：

1. 哪些测试可以由 Codex 在本机自动完成。
2. 哪些真实联调可以由 Codex 执行，但需要你提供凭据、测试账号或测试群。
3. 哪些真实业务效果必须由你在企微/微信客户端或管理后台人工确认。

默认原则：

- 单元测试和 fake HTTP/WebSocket 测试必须全自动。
- 真实接口测试默认跳过，只有显式设置 `QWSAAS_REAL_TESTS=1` 才运行。
- 有副作用测试必须再单独设置 `QWSAAS_REAL_MUTATION_TESTS=1`。
- 破坏性测试不进自动化，只能在你明确说“用测试账号执行这个接口”后单独跑。
- 所有真实测试只使用测试账号、测试联系人、测试群、测试标签和测试文件。

## 测试分层

### L0：静态与单元测试

执行方：Codex。

运行时机：每个实现任务内、发布前。

特点：

- 不访问真实 Juhe。
- 不访问真实 `34789` CDN 转换服务。
- 不访问真实 S3/MinIO。
- 使用 fake HTTP client、fake boto3 client、fake WebSocket。

覆盖内容：

- `QwSaasClient.request()` / `request_private()` payload。
- `/cloud/*`、`/cdn/*`、`/msg/*` wrapper path 和 payload。
- storage config、upload、presign、delete 的 fake client 行为。
- 入站附件 `qpic / 30 / https / *` 分流逻辑。
- 回调 parser、枚举、消息 flag helper。
- 账号、实例、联系人、群、标签 wrapper 的参数校验和 path。

验收命令：

```bash
uv run --extra dev pytest
git diff --check
```

### L1：真实基础联通测试

执行方：Codex 可执行。

前提：不需要 Juhe 业务凭据，或只需要非敏感公开 URL。

覆盖内容：

| 测试项 | Codex 可测 | 需要你提供 | 是否有副作用 |
| --- | --- | --- | --- |
| 获取 wework cdn Swagger | 是 | 无 | 否 |
| 校验 `http://124.220.81.138:34789/swagger/doc.json` 包含 5 个 `/cloud/*` path | 是 | 无 | 否 |
| `private_base_url` 拼接逻辑 | 是 | 无 | 否 |
| S3 endpoint DNS/端口可达性 | 部分 | endpoint | 否 |

建议命令：

```bash
curl -fsS http://124.220.81.138:34789/swagger/doc.json
```

通过标准：

- Swagger 可获取。
- 包含 `/cloud/c2c_upload`、`/cloud/c2c_download`、`/cloud/big_upload`、
  `/cloud/big_download`、`/cloud/wx_download`。
- 不把 `34789` 当成 S3 endpoint。

### L2：真实 storage 测试

执行方：Codex 可执行。

前提：你提供一套测试用 S3-compatible 凭据，bucket 只用于测试或允许写入测试前缀。

需要环境变量：

```bash
export QWSAAS_REAL_TESTS=1
export QWSAAS_STORAGE_ENDPOINT_URL="http://124.220.81.138:9000"
export QWSAAS_STORAGE_BUCKET="wework"
export QWSAAS_STORAGE_ACCESS_KEY="..."
export QWSAAS_STORAGE_SECRET_KEY="..."
export QWSAAS_STORAGE_REGION="us-east-1"
export QWSAAS_STORAGE_PREFIX="qwsaas-real-test"
export QWSAAS_STORAGE_ADDRESSING_STYLE="path"
export QWSAAS_STORAGE_URL_EXPIRES_SECONDS="900"
```

覆盖内容：

| 测试项 | Codex 可测 | 需要你提供 | 是否有副作用 |
| --- | --- | --- | --- |
| 上传小文本文件到测试前缀 | 是 | S3 凭据 | 写入临时对象 |
| 生成 presigned GET URL | 是 | S3 凭据 | 否 |
| 用 presigned URL 下载并校验内容 | 是 | S3 凭据 | 读取 |
| 删除测试对象 | 是 | S3 凭据 | 删除测试对象 |
| 解析 path-style object URL | 是 | endpoint/bucket | 否 |

通过标准：

- 上传对象 key 在 `QWSAAS_STORAGE_PREFIX` 下。
- presigned URL 可下载，内容与原文件一致。
- 测试结束后对象被删除。
- 删除失败必须报错，不允许静默留下测试对象。

### L3：真实 Juhe 只读接口测试

执行方：Codex 可执行。

前提：你提供测试实例凭据。

需要环境变量：

```bash
export QWSAAS_REAL_TESTS=1
export JUHE_APP_KEY="..."
export JUHE_APP_SECRET="..."
export JUHE_GUID="..."
export JUHE_BASE_URL="https://chat-api.juhebot.com"
export JUHE_PRIVATE_BASE_URL="http://124.220.81.138:34789"
```

只读测试范围：

| 模块 | 接口 | Codex 可测 | 需要你提供 | 是否有副作用 |
| --- | --- | --- | --- | --- |
| client | `request("/cdn/get_cdn_info")` | 是 | app/guid | 否 |
| cdn | `get_cdn_info` | 是 | app/guid | 否 |
| user | `get_profile` | 是 | app/guid | 否 |
| user | `get_corp_info` | 是 | app/guid | 否 |
| user | `get_bind_wxinfo` | 是 | app/guid | 否 |
| room | `get_room_list` | 是 | app/guid | 否，但可能不全 |
| room | `batch_get_room_detail` | 是 | 测试 `room_id` | 否 |
| room | `batch_get_member_detail` | 是 | 测试 `room_id` | 否 |
| contact | `batch_get_userinfo` | 是 | 测试 `user_id` | 否 |
| label | `sync_label_list` | 是 | app/guid | 否 |

通过标准：

- HTTP 200。
- SDK 不抛 `QwSaasApiError`。
- 返回结构中关键字段可读。
- 不要求真实返回内容完全固定，因为账号状态和实例数据会变化。

频控要求：

- 默认串行执行。
- 每分钟真实请求数控制在 30 次以内，低于官方 100 次/分钟限制。
- 失败重试最多 1 次，避免误触发风控。

### L4：真实 CDN 上传/下载测试

执行方：Codex 可执行，但需要测试凭据和测试素材。

前提：

- L2 storage 已通过。
- L3 `get_cdn_info` 已通过。
- `JUHE_PRIVATE_BASE_URL` 指向当前 CDN 转换服务。

测试素材：

```text
qwsaas-real-test.txt
qwsaas-real-test.jpg
qwsaas-real-test.mp3
qwsaas-real-test.mp4
```

覆盖内容：

| 测试项 | Codex 可测 | 需要你提供 | 是否有副作用 |
| --- | --- | --- | --- |
| storage 上传测试文件并得到 presigned URL | 是 | S3 凭据 | 写临时对象 |
| `/cloud/c2c_upload` 上传小文件 URL | 是 | Juhe 凭据、S3 凭据 | 生成 CDN 资源 |
| `/cloud/big_upload` 上传大文件 URL | 是 | Juhe 凭据、S3 凭据、大文件 | 生成 CDN 资源 |
| `/cloud/c2c_download` 下载回调样本资源 | 是 | 真实回调样本字段 | 读取 |
| `/cloud/wx_download` 下载微信私有 URL | 是 | 真实回调样本字段 | 读取 |
| `/cloud/big_download` 下载大文件资源 | 是 | `*` 文件样本或回调样本 | 读取 |

通过标准：

- 上传响应包含发送消息所需字段，例如 `file_id`、`file_size`、`file_md5`、`aes_key`。
- 下载响应能解析出可访问 URL 或对象 URL。
- 如果返回私有对象 URL，SDK 能通过 storage 生成 presigned URL 或明确返回
  `requires_object_store_auth=True`。

你需要提供的回调样本字段：

```json
{
  "file_id": "...",
  "file_name": "...",
  "file_size": 123,
  "file_md5": "...",
  "aes_key": "...",
  "auth_key": "...",
  "download_url": "...",
  "base_request": {
    "cdn_dns": "...",
    "client_version": "...",
    "corp_id": "...",
    "vid": "..."
  }
}
```

### L5：真实消息发送测试

执行方：Codex 可发起，最终效果需要你确认。

前提：

- 使用测试私聊或测试群。
- 你提供目标 `conversation_id`。
- 发送测试内容不会影响真实客户。

需要环境变量：

```bash
export QWSAAS_REAL_SEND_TESTS=1
export QWSAAS_TEST_DM_CONVERSATION_ID="S:..."
export QWSAAS_TEST_ROOM_CONVERSATION_ID="R:..."
```

覆盖内容：

| 消息类型 | Codex 可发起 | 需要你确认 | 需要你提供 |
| --- | --- | --- | --- |
| 文本消息 | 是 | 客户端收到且内容正确 | 测试会话 |
| 文件消息 | 是 | 客户端收到文件且可打开 | 测试会话、storage |
| 图片消息 | 是 | 图片可预览 | 测试会话、storage |
| 语音消息 | 是 | 客户端显示为语音或可播放文件 | 测试会话、storage |
| 视频消息 | 是 | 视频可预览或可下载 | 测试会话、storage |
| 群 @ 消息 | 是 | 群内 @ 展示正确 | 测试群、被 @ 用户 |
| 引用消息 | 部分 | 引用关系正确 | 一条可引用的真实消息 |
| 撤回消息 | 部分 | 被撤回 | SDK 刚发出的测试消息 |

通过标准：

- API 返回成功。
- `message_id` 或等价字段可记录。
- 你在企微/微信客户端确认实际展示符合预期。
- 本地文件发送后不暴露本地路径。

### L6：真实回调测试

执行方：需要你配合。

原因：回调依赖公网通知地址、真实消息触发、实例配置，以及客户端实际行为。

Codex 可做：

- 提供临时 webhook 接收服务或验证现有 webhook。
- 解析收到的真实 callback payload。
- 校验 `notify_type`、`seq`、`appinfo`、`referid`、`flag`、附件字段。
- 用真实 payload 回放 SDK parser。

你需要做：

- 在测试实例中设置通知地址，或提供已配置好的回调日志。
- 从测试微信/企微账号发送文本、图片、文件、语音、视频到测试会话。
- 触发已读、撤回、引用等状态变化。
- 确认客户端侧显示和 SDK 解析结果一致。

通过标准：

- 原消息 `referid == "0"` 可识别。
- 已读/撤回/引用等附属回调不会被误当成普通新消息。
- 附件字段能被 `resolve_callback_attachment_target()` 分流。
- 重复回调不会导致 SDK parser 丢失 raw payload。

### L7：真实联系人/群/标签变更测试

执行方：需要你明确授权后，Codex 才能执行；部分必须由你人工确认。

安全原则：

- 只用测试联系人、测试群、测试标签。
- 每个变更测试都要有回滚步骤。
- 破坏性接口默认不自动跑。

可由 Codex 执行但需要授权的接口：

| 模块 | 接口 | 风险 | 需要你提供 | 回滚 |
| --- | --- | --- | --- | --- |
| label | `create_label` | 低 | 测试标签名 | `delete_label` |
| label | `modify_label` | 低 | 测试标签 ID | 改回原名 |
| label | `contact_add_label` | 中 | 测试联系人、标签 ID | 移除标签，如果官方支持 |
| contact | `update_contact` | 中 | 测试联系人 | 改回原值 |
| room | `modify_room_name` | 中 | 测试群 | 改回原群名 |
| room | `modify_room_notice` | 中 | 测试群 | 清空或改回公告 |
| room | `invite_room_member` | 中 | 测试群、测试成员 | 移除测试成员 |
| room | `remove_room_member` | 高 | 测试群、测试成员 | 重新邀请 |

必须你亲自确认或单独审批的接口：

| 接口 | 原因 |
| --- | --- |
| `logout` | 可能影响实例在线状态 |
| `stop_client` | 会停止实例 |
| `restore_client` | 可能改变实例状态 |
| `update_client` | 可能触发升级 |
| `delete_contact` | 删除联系人有业务风险 |
| `op_black_list` | 黑名单影响真实沟通 |
| `quit_room` | 退出群不可轻易恢复 |
| `dismiss_room` | 解散群风险极高 |
| `change_room_master` | 群主转让影响权限 |
| `room_add_admin` / `room_remove_admin` | 改变群权限 |
| `set_proxy` | 可能影响实例网络 |
| `set_notify_url` | 可能影响生产回调 |

## 建议的真实测试脚本设计

实现代码后，新增真实测试文件，但默认跳过：

```text
tests/real/test_real_connectivity.py
tests/real/test_real_storage.py
tests/real/test_real_cdn_flows.py
tests/real/test_real_send_messages.py
tests/real/test_real_callbacks_replay.py
```

pytest marker：

```python
pytestmark = pytest.mark.real
```

跳过规则：

```python
pytest.skip("set QWSAAS_REAL_TESTS=1 to run real integration tests")
```

建议命令：

```bash
QWSAAS_REAL_TESTS=1 uv run --extra dev pytest tests/real/test_real_connectivity.py -q
QWSAAS_REAL_TESTS=1 uv run --extra dev pytest tests/real/test_real_storage.py -q
QWSAAS_REAL_TESTS=1 QWSAAS_REAL_SEND_TESTS=1 uv run --extra dev pytest tests/real/test_real_send_messages.py -q
```

变更类接口单独命令：

```bash
QWSAAS_REAL_TESTS=1 QWSAAS_REAL_MUTATION_TESTS=1 uv run --extra dev pytest tests/real/test_real_mutations.py -q
```

## 发布前最低真实验收

`v0.3.0` 发布前，建议至少完成：

1. L0 全量自动测试通过。
2. L1 wework cdn Swagger 联通通过。
3. L2 storage 上传、presign、下载、删除通过。
4. L3 `get_cdn_info` 和 `get_profile` 真实只读通过。
5. L4 小文件 C2C 上传通过。
6. L5 至少一个测试会话收到文本消息和一个本地文件消息。
7. L6 至少一个真实图片或文件回调可被 parser 解析，并能得到可访问附件 URL。

暂不作为发布阻塞：

- 登出、停止、恢复、升级实例。
- 删除联系人、黑名单、退群、解散群、群主转让。
- 所有朋友圈、视频号、微信小店、合并转发能力。

## 责任分工

Codex 负责：

- 编写和运行 L0 自动化测试。
- 在你提供凭据后运行 L1-L5 中的非破坏性真实测试。
- 用你提供的真实 payload 做回放测试。
- 记录测试结果、失败请求、响应摘要和复现命令。

你负责：

- 提供测试环境凭据和测试对象。
- 在企微/微信客户端确认真实消息展示。
- 配置或提供真实回调。
- 审批任何变更类或破坏性接口测试。
- 判断测试账号和测试群是否允许被修改。

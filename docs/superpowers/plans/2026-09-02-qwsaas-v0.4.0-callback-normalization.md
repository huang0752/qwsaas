# qwsaas v0.4.0 Callback Normalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the breaking `qwsaas 0.4.0rc1` callback contract with pure protocol parsing, separate identity normalization, safe diagnostics, source-specific live/batch/sync adapters, account-scoped logical keys, and release gates that prevent a final `v0.4.0` before real callback acceptance.

**Architecture:** `callbacks.py` becomes a public facade over focused envelope, message, attachment, identity, redaction, and sync modules. Protocol parsing is deterministic and account-independent; identity normalization is a second public operation. Live 11010, verified 11013, and sync records share one single-record parser but never impersonate one another.

**Tech Stack:** Python 3.11+, frozen dataclasses, `Enum`/`IntEnum`/`IntFlag`, SHA-256 canonical JSON fingerprints, pytest, Ruff, uv.

# qwsaas v0.4.0 release gate

Current package version: `0.4.0rc1`.

The RC implements the breaking callback model, strict envelope dispatch, identity normalization, independent sync-record parsing, safe diagnostics, logical message keys, sent-result parsing, and fixture scanning.

Do not create or publish a final `v0.4.0` tag until [the real callback matrix](../callback-real-validation.md) is complete. In particular, 11013 parsing and room direction remain intentionally unavailable rather than inferred. Private sender/receiver direction is implemented as the expected invariant but remains part of the final-release evidence gate.

Creating a commit, tag, GitHub release, or package publication requires separate release authorization; implementation completion does not imply publication.
